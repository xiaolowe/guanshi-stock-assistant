# 观市 · 股票小助手

一个本地运行的 A 股行情看板与技术面分析工具。行情、K 线与榜单数据通过本地 Node 服务代理东方财富公开接口，浏览器端无需任何 API Key。

## 功能

- **指数概览**：上证指数、深证成指、创业板指、沪深 300，附 32 日迷你走势。
- **个股搜索**：支持代码、名称、拼音，`/` 键快速聚焦搜索框。
- **行情图表**：分时、日 K、周 K、月 K；MA5 / MA10 / MA20 均线（可点击图例单独隐藏）、成交量、十字光标与悬浮明细。
- **自选股**：保存在浏览器 localStorage，最多 30 只，点击行情卡右上角星标即可增减。
- **市场榜单**：涨幅榜、跌幅榜、成交额榜，点击任意标的直接查看。
- **技术面小助手**：根据均线结构、RSI(14)、MACD、量能与 60 日位置生成 0–100 评分、信号清单、支撑压力位与价格区间。
- **数据表视图**：图表右下角「数据表」可展开最近 40 条行情记录，便于核对与无障碍阅读。
- **响应式布局**：桌面双栏，移动端自动堆叠。

## 快速开始

要求 Node.js 18 或更高版本（使用内置 `fetch`，无第三方依赖）。

```bash
npm start
```

然后打开：

```bash
open http://127.0.0.1:5173
```

开发模式（文件变更自动重启）：

```bash
npm run dev
```

可选环境变量：

```bash
PORT=8080 HOST=0.0.0.0 npm start
```

## 项目结构

```
server.mjs          本地 HTTP 服务：静态文件 + 行情 API 代理 + 短时缓存
public/
  index.html        页面结构
  styles.css        深色行情终端视觉
  app.js            行情、搜索、自选、榜单、技术指标与页面交互
  chart.js          Canvas 自绘 K 线 / 分时图（含十字光标）
```

后端接口：`/api/quote`、`/api/kline`、`/api/trends`、`/api/search`、`/api/rank`。所有参数都会在服务端校验，接口结果做 3–300 秒的短时缓存，避免频繁请求上游。

## 交互提示

- 输入股票代码 / 名称 / 拼音后，用 `↑` `↓` 选择、`Enter` 确认、`Esc` 关闭。
- 图表上移动鼠标查看每根 K 线或每分钟价格；点击均线图例可隐藏该条均线。
- 交易时段每 15 秒自动刷新行情，非交易时段为 60 秒；右上角可手动刷新。
- 行情时间为北京时间；状态标签会显示交易中 / 午间休市 / 已收盘。
